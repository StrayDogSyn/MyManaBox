# CardForge Screenshots

This folder contains screenshots of the CardForge GUI for documentation.

## Required Screenshots

Please capture and save the following screenshots:

### Main Screenshots (Required)

| Filename | Description | How to Capture |
|----------|-------------|----------------|
| `qt_main_window.png` | Full application window | Launch `python run_qt_gui.py`, capture entire window |
| `qt_collection_table.png` | Collection browser table | Focus on the table area with cards visible |
| `qt_card_details.png` | Card details panel | Select a card and capture the details panel |
| `qt_analytics.png` | Analytics/statistics dashboard | Capture the stats area at top of window |

### Additional Screenshots (Optional)

| Filename | Description |
|----------|-------------|
| `qt_search.png` | Search bar with active filter |
| `qt_dark_theme.png` | Full window showing dark purple theme |
| `qt_sort_by_price.png` | Table sorted by price column |
| `qt_foil_cards.png` | Showing foil cards highlighted |

## Capture Tips

1. **Resolution**: Use at least 1920x1080 display
2. **Theme**: Ensure dark purple theme is active (default)
3. **Data**: Have cards loaded in your collection for visual appeal
4. **Clean**: Close any dialogs/popups before capture

## Windows Screenshot Tools

- `Win + Shift + S` - Snipping Tool (recommended)
- `Alt + Print Screen` - Active window only
- `Print Screen` - Full screen

Save screenshots as PNG format for best quality.
